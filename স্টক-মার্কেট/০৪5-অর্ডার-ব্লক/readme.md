# অর্ডার ব্লক

ট্রেডিং-এ Order Block (OB) হলো এমন একটি প্রাইস জোন যেখানে বড় প্রতিষ্ঠান (ব্যাংক, হেজ ফান্ড, মার্কেট মেকার) বড় পরিমাণে Buy বা Sell অর্ডার দিয়েছে বলে ধারণা করা হয়। Smart Money Concept (SMC)-এ এটি খুব জনপ্রিয় একটি ধারণা।

## সহজভাবে বুঝুন

ধরুন XYZ - আইটেম এর দাম কিছুক্ষণ নিচে নামছিল। হঠাৎ একটি ছোট bearish candle-এর পর দাম খুব শক্তিশালীভাবে উপরে উঠতে শুরু করল।এই ক্ষেত্রে, উপরে ওঠার আগে যে শেষ bearish candle ছিল, সেটিকেই Bullish Order Block বলা হয়। কারণ ধারণা করা হয়, বড় খেলোয়াড়রা ওই এলাকায় Buy Order জমা করেছিল। পরে যখন দাম আবার সেই জোনে ফিরে আসে, তখন সেখান থেকে আবার উপরে যাওয়ার সম্ভাবনা থাকে।

### বুলিশ অর্ডার ব্লক সংজ্ঞা

একটি ঊর্ধ্বমুখী (বুলিশ) মুভের আগে যে শেষ বিয়ারিশ ক্যান্ডেল থাকে, পরে দাম যদি আবার দেখতে বিয়ারিশ ক্যান্ডেল - এর মধ্যে ফিরে আসে, অনেক ট্রেডার বাই এন্ট্রি খোঁজে।

### বিয়ারিশ অর্ডার ব্লক সংজ্ঞা

একটি নিচের মুখী (বেয়ারিশ) মুভের আগে যে শেষ বুলিশ ক্যান্ডেল থাকে, পরে দাম আবার দাম ওই জোনে ফিরে এলে অনেক ট্রেডার সেল এন্ট্রি খোঁজে।

## অর্ডার ব্লক কিভাবে খুঁজবেন?

### একটি ভালো অর্ডার ব্লক-এর বৈশিষ্ট্য

* Strong Impulse Move: Order Block থেকে দাম দ্রুত ও শক্তিশালীভাবে বের হয়ে যেতে হবে।

* Break of Structure (BOS): দাম আগের High বা Low ভেঙে নতুন Structure তৈরি করবে।

* Fresh Zone: জোনটি বারবার টেস্ট হওয়া উচিত নয়। প্রথম বা দ্বিতীয় টেস্ট সাধারণত বেশি কার্যকর।

* Higher Timeframe Support: 4H, Daily বা Weekly Timeframe-এর Order Block সাধারণত বেশি শক্তিশালী।

## ট্রেড এন্ট্রি উদাহরণ

### বায়িং সেটআপ

* Uptrend খুঁজুন।
* শেষ bearish candle চিহ্নিত করুন।
* Candle-এর High-Low মার্ক করুন।
* দাম আবার সেই জোনে আসা পর্যন্ত অপেক্ষা করুন।
* Bullish confirmation পেলে Buy করুন।
* Stop Loss Order Block-এর নিচে রাখুন।

### সেলিং সেটআপ

* Downtrend খুঁজুন।
* শেষ bullish candle চিহ্নিত করুন।
* জোন মার্ক করুন।
* দাম আবার জোনে এলে অপেক্ষা করুন।
* Bearish confirmation পেলে Sell করুন।
* Stop Loss Order Block-এর উপরে রাখুন।

## একটি গুরুত্বপূর্ণ বিষয়

অনেক নতুন ট্রেডার মনে করেন Order Block মানেই দাম সেখান থেকে ঘুরে যাবে। বাস্তবে তা নয়।

***Order Block শুধু একটি সম্ভাব্য রিঅ্যাকশন জোন। তাই সবসময়:***

* Stop Loss ব্যবহার করুন
* Risk Management অনুসরণ করুন
* Market Structure দেখুন
* Confirmation ছাড়া Entry নেবেন না

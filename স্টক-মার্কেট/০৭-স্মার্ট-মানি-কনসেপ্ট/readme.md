# ০৭ - স্মার্ট মানি কনসেপ্ট (Smart Money Concept - SMC)

Institution আসলে কীভাবে Market Move করে এবং কোথায় Entry নেয়?"
এখান থেকেই Smart Money Concept (SMC)-এর মূল অংশ শুরু হয়।

## স্মার্ট মানি কনসেপ্ট (এসএমসি) - Smart Money Concept (SMC) কী?

SMC হলো এমন একটি Trading Framework যা Market-কে Retail Trader-এর চোখে নয়, বরং Institution, Bank, Fund Manager এবং Market Maker-এর চোখে দেখার চেষ্টা করে।

***Retail Trader ভাবে:***

```text
RSI Overbought
=
Sell

RSI Oversold
=
Buy
```

***Smart Money Trader ভাবে:***

```text
Liquidity কোথায়?

Institution কোথায়?

Structure Break হয়েছে?

Order Block কোথায়?

FVG কোথায়?
```

# 1. BOS (Break Of Structure)

এটি Trend Continuation-এর Confirmation।

## Bullish BOS

```text
        HH
         ▲
         │
         │

Price Breaks
Above High
```

Meaning:

Buyer Control-এ আছে।

Uptrend Continue হতে পারে।

## Bearish BOS

```text
Old Low
   ▼

Price Breaks
Below Low
```

Meaning:

Seller Control-এ আছে।

# DSE Example

```text
50
↓
60
↓
55
↓
65
```

65 যদি 60-এর High Break করে:

Bullish BOS।

# 2. CHOCH (Change Of Character)

Trend Change-এর প্রথম Warning।

## Example

```text
HH
↓
HL
↓
HH
↓
HL Break
```

এখানে Uptrend দুর্বল হচ্ছে।

CHOCH তৈরি হচ্ছে।

# CHOCH vs BOS

অনেক Trader Confuse হয়।

## BOS

```text
Trend Continue
```

## CHOCH

```text
Trend Change শুরু
```

সহজ Rule:

```text
CHOCH First

BOS Later
```

# 4. Order Block (OB)

SMC-এর সবচেয়ে জনপ্রিয় Concept।

## Order Block কী?

Institution যে Candle থেকে বড় Move শুরু করেছে সেই Candle।

## Bullish Order Block

```text
Last Bearish Candle

↓

Strong Rally
```

Visual

```text
🟥

▲
▲
▲
▲
▲
```

শেষ Bearish Candle = Bullish Order Block

## Bearish Order Block

```text
🟩

▼
▼
▼
▼
```

শেষ Bullish Candle = Bearish Order Block

# কেন Order Block কাজ করে?

কারণ:

Institution-এর সব Order একবারে Fill হয় না।

তারা পরে Zone-এ ফিরে আসে।

# DSE Example

ধরুন:

```text
100
101
102
103
```

একটি Bearish Candle

```text
101
```

তারপর

```text
110
120
130
140
```

101-এর Candle

Bullish Order Block।

# Order Block Entry Model

```text
Liquidity Sweep
      ↓
CHOCH
      ↓
BOS
      ↓
OB Retest
      ↓
Buy
```

# 5. Breaker Block

Failed Order Block।

## Example

Bullish OB তৈরি হয়েছিল।

কিন্তু Price:

```text
Zone Break
```

পরে:

```text
Support
↓
Resistance
```

হয়ে যায়।

এটাই Breaker Block।

# 6. Mitigation Block

Institution-এর অসম্পূর্ণ Order Fill করার Zone।

অনেক সময়:

```text
Price Fast Move
```

Institution পরে Price ফিরিয়ে আনে।

Missing Order Fill করে।

এটিকে Mitigation বলে।

# 7. Fair Value Gap (FVG)

ICT-এর সবচেয়ে গুরুত্বপূর্ণ Concept।

# FVG কী?

Market-এর Imbalance।

যখন Price খুব দ্রুত Move করে:

```text
Candle 1

Candle 2

Candle 3
```

Middle Candle এত বড় হয় যে Gap তৈরি হয়।

Visual

```text
High
   │

   Gap

   │
Low
```

এটাই FVG।

# কেন FVG গুরুত্বপূর্ণ?

Institution Efficiency পছন্দ করে।

Market প্রায়ই FVG Fill করতে ফিরে আসে।

# Bullish FVG

```text
Strong Rally

Gap

Continue
```

Price পরে Gap Fill করতে আসে।

তারপর:

```text
Continue Up
```

# Bearish FVG

```text
Strong Drop

Gap

Continue Down
```

# FVG + OB Setup

Professional Entry:

```text
OB

Inside

FVG
```

এটি High Probability Zone।

# 8. Premium & Discount

↓

Swing High

```text

```

# ০৫। লিনাক্স থিম কাস্টমাইজেশন

> Ubuntu 26 (GNOME)-কে সুন্দর, আধুনিক এবং Windows 11-এর মতো ব্যবহারবান্ধব করে তোলার পূর্ণাঙ্গ বাংলা গাইড।

## শেখার উদ্দেশ্য
- GNOME Customization
- Themes, Icons, Cursor
- Dash to Panel
- ArcMenu
- Fluent Theme
- Backup ও Restore

## প্রয়োজনীয় প্যাকেজ
```bash
sudo apt update
sudo apt install -y gnome-tweaks gnome-shell-extension-manager git curl wget
```

## জনপ্রিয় Extensions
- Dash to Panel
- ArcMenu
- User Themes
- Blur My Shell

## Fluent Theme
```bash
git clone https://github.com/vinceliuice/Fluent-gtk-theme.git
cd Fluent-gtk-theme
./install.sh
```

## Fluent Icons
```bash
git clone https://github.com/vinceliuice/Fluent-icon-theme.git
cd Fluent-icon-theme
./install.sh
```

## GNOME Tweaks
Appearance → Theme → Fluent

## অধ্যায়ের সারাংশ
এই অধ্যায়ে Ubuntu GNOME-কে Windows 11-এর মতো কাস্টমাইজ করা শিখেছেন।
